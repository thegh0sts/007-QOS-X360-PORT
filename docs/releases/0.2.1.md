Update to the 007: Quantum of Solace (Xbox 360) PC port.

**You need your own copy of the game.** `QuantumOfSolace.exe` is the launcher and installer; it builds the game on your PC from your Xbox 360 disc image.

## Updating from 0.2.0
Download `QuantumOfSolace.exe` below and run it (or use **Check for updates** in the launcher). The game itself hasn't changed, so it doesn't need rebuilding.

## Fixed
- **The desktop shortcut works.** Earlier installs left an empty file called **007** on the desktop instead of a shortcut: it wouldn't open and had no icon. The shortcut is now **007 - Quantum of Solace**, with the game's icon, and it's put on the desktop Windows actually uses (also when OneDrive has moved it). To get it, run **Game files → Reinstall** once with this version; that also removes the empty **007** file. You can also just delete that file yourself.
