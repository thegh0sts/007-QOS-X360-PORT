Update to the 007: Quantum of Solace (Xbox 360) PC port.

**You need your own copy of the game.** `QuantumOfSolace.exe` is the launcher and installer; it builds the game on your PC from your Xbox 360 disc image.

## Updating from 0.1.2
Download `QuantumOfSolace.exe` below and run it (or use **Check for updates** in the launcher). It updates the renderer and rebuilds the game, now with multiplayer as well, so the rebuild takes a little longer. Your saves and settings stay.

## What's new
- **Multiplayer (System Link).** Choose **MULTIPLAYER** on the game's main menu to start it, and leave it to return to single player. Host or join System Link games with other PCs on your local network. The display, graphics and control settings are the same as in single player.
- **Gamertag** (launcher, Multiplayer tab): your name in System Link games. Every player in a game needs a different one. Your profile's ID (XUID) is shown there too; it's made once for each install.
- **DLC: the Camille Map Pack** (Canals, Baggage, Cistern, Dam). In the Multiplayer tab, choose the folder with your map pack file, as copied from an Xbox 360 drive. The launcher lists the packs it finds, and multiplayer installs them the first time it starts (that start takes a few seconds longer). The maps then show in the map list with their names and pictures. Everyone in a game needs the pack to play its maps.
- **Keyboard and mouse in multiplayer:** mouse look, the same key layout as single player, Esc goes back in menus, and key prompts.
- **Button prompts follow the controller in use:** with an Xbox and a PlayStation controller connected, the prompts switch to whichever you pressed last.
- **Switching controllers works:** with two controllers connected, both control the game. Before, switching back to the first one could leave it unresponsive.
- **Keyboard and mouse mode turns controllers off**, so a connected pad no longer moves you while you play with the keyboard.
- **Separate shader caches** for single player and multiplayer (Game files tab), each with its own Clear and rebuild.
- If multiplayer hits an error, it restarts and shows the error message, as on the console.

## Known issues
- Work in progress: not every level has been played through yet.
- **Multiplayer has only been tested with two copies on one PC.** Games between two PCs on a network should work but haven't been tested yet. Windows may ask to let the game through the firewall the first time: allow it on private networks.
- **Xbox LIVE in the multiplayer menu doesn't work yet:** use System Link.
- Auto in the Controls tab is controllers only. For keyboard and mouse, choose Keyboard and mouse.
- At render resolutions above 720p, some cutscenes' black letterbox bars are see-through (the picture shows through them).
- The balance beam hint shows no button.
- Some scripted moments may get stuck above 30 FPS: set the frame rate to 30 in the launcher if a mission won't progress.
