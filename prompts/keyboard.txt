# Keyboard and mouse button pictures for 007: Quantum of Solace, read by the native renderer

# (src/kbm_binds.cpp, as the PC game's manual): A E (cover), B C (stance), X F (use; R reloads too), Y Space, LB 1,

# changed on the Rebind screen still shows its default key here.

# tools/make_kbm_prompts.py (the takedown discs tk_, km_backspace, k_space_sq).
